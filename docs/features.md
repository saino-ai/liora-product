# Feature overview

Liora is modular. Features that depend on external software, accounts, models, or hardware become available only after those dependencies are configured.

## Chat, memory, and information

- Streaming chat with local AI providers
- Conversation and project history
- Long-term memory and semantic retrieval
- Document ingestion and local search
- Web search with source links when enabled
- File attachments and supported image input

## Local AI and coding agents

- Ollama as the primary local AI connection
- LM Studio and llama.cpp server connections
- Model discovery, selection, and model-specific settings
- Codex CLI and Claude Code CLI integration when installed and signed in
- Provider health checks, error normalization, and fallback behavior

## Work Mode

- Project and folder explorer
- Conversation-centred workspace
- Plan, task, context, Git, tests, and diagnostics panels
- Integrated PTY terminal for supported Windows shells
- File editing, diffs, undo, redo, and session recovery
- Configurable approval and automation rules

## Voice

- Microphone input and speech recognition through configured engines
- Voice conversation with silence and interruption controls
- Speech output through supported TTS engines
- Optional engine startup and diagnostic controls

## Creative Mode

- Image, video, and music workflow entry points
- ComfyUI connection and model checks
- Prompt and reference-material organisation
- Generation history and asset-library integration
- Optional capabilities remain disabled when their generation environment is unavailable

## Extensions and PC tools

- MCP server management
- Skills and plugins
- Web and local automation
- PC-operation tools with configurable permissions
- Financial actions remain confirmation-gated
- Backup, restore, diagnostics, audit records, and Safe Mode

Actual availability depends on the installed Liora version and the external environments configured on the PC.
