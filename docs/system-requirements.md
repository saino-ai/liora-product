# System requirements

Liora is intended for people comfortable configuring Windows software and local AI environments.

## Base application

- 64-bit Windows 10 or Windows 11
- An account with permission to install desktop software
- Sufficient storage for the application, logs, backups, and selected AI models
- Internet access for product delivery, updates, web search, OAuth, cloud AI, and optional external services

## Local AI

CPU, memory, GPU, and storage requirements depend primarily on the selected model and provider. Large models may require substantial system memory or GPU memory and can respond slowly on unsupported hardware.

Before purchase, decide which provider and model class you intend to use and confirm its requirements separately. Liora does not include local model files in the base installer.

## Optional environments

- Ollama, LM Studio, or llama.cpp for local AI
- Codex CLI or Claude Code CLI for their corresponding development-agent workflows
- Supported speech-recognition and speech-output engines for voice features
- ComfyUI and compatible models for local generation workflows
- Git and supported shells for development workflows
- Accounts, API keys, or OAuth login for optional cloud and search services

## Recommended preparation

- Be able to install and update Windows applications
- Be able to download and configure AI models
- Be able to read error messages and run the included diagnostics
- Keep adequate free storage and a current backup
- Use a personal test project before enabling automation on important files

Contact SAINO through the [official product page](https://sainoweb.com/en/products/liora) if you need to confirm whether a planned configuration is within the published support scope.
