# Security Policy

## Reporting a vulnerability

Please do not publish security vulnerabilities in a public issue.

Use the [SAINO contact form](https://sainoweb.com/en/contact?product=liora) and include:

- the affected Liora version;
- the Windows version;
- a concise description of the issue;
- reproduction steps that do not contain passwords, API keys, personal information, or confidential files; and
- whether the issue could affect files, credentials, external tools, or PC operation.

SAINO will review the report and reply through the contact information you provide. Do not send executable files, private repositories, access tokens, or sensitive logs unless SAINO has first agreed on a safe transfer method.

## Supported release

Liora is currently distributed as a limited beta. Security updates and supported versions are announced through the official delivery channel and the [SAINO website](https://sainoweb.com/en/products/liora).
